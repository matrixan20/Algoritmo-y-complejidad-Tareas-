Las pruebas y mediciones de estos algoritmos fueron realizadas en un computador portátil con un procesador AMD Ryzen 3 7320U y 8 GB de memoria RAM DDR5. El entorno de ejecución utilizado fue Windows con el subsistema de Linux (WSL), y el código fue compilado utilizando \texttt{g++} con la bandera de optimización \texttt{-O3}. Los datasets utilizados para las pruebas corresponden a los arreglos y matrices generados según los parámetros del enunciado mediante los scripts de Python.
